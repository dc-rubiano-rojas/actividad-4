# Proyecto de Visualización de Mortalidad en Colombia

Este proyecto es una aplicación web interactiva creada con Dash y Plotly que muestra visualizaciones sobre la mortalidad en Colombia.

---

## Instrucciones para ejecutar el proyecto

1. **Activar el ambiente virtual:**

   ```bash
   pipenv shell

2. **Instalar dependencias:**

   ```bash
   pipenv install -r requirements.txt

3. **Ejecutar aplicación:**

   ```bash
   python app.py
